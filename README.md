# Drone Hunt — a Duck Hunt Remake Controlled by Colour Tracking

Duck Hunt reworked with drones: drones fly across the screen and you shoot them by pointing a coloured marker at the camera. In the original build the "trigger" was a glove wired to a hacked mouse circuit. Computer-vision learning project, 2022.

![Drone Hunt](https://user-images.githubusercontent.com/105288469/186954751-1eaafe4a-7520-4a7a-b1e4-3f63151667a4.gif)

[Watch the video](https://youtu.be/_bXecUOMD4c)

**Stack:** Python · OpenCV · cvzone · NumPy

Note: `Drone Hunt.py` loads its images from absolute Windows paths; point them at your own image folder before running.
